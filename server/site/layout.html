Stratux NX provides supplemental situational awareness only. It is not certified avionics and must not be used as the sole source of navigation, traffic, weather, attitude, terrain or flight information.

Stratux NX is an independent distribution and is not an official upstream Stratux release. Starlink, ForeFlight, Garmin Pilot, SkyDemon, Sentry, Stratus, Raspberry Pi and other names are trademarks of their respective owners and are used only to describe compatibility.
