What's in a release

Each release on GitHub has three files:

  • SD card image (image_…-stratux-lite.zip, about 730 MB). Use this for a new install or to start from scratch.
  • Update package (stratux-…-arm64.deb). Use this to update a Stratux NX that has no Internet, from Settings → Software Update.
  • Source archive (…-corresponding-source.tar.gz). The exact source used to build the release.

Releases are currently marked as beta. Read the release notes before updating equipment you fly with.

Before you start

  • Stratux hardware: a Raspberry Pi with the ADS-B radios and a GPS. Any standard Stratux build works. Don't have one yet? See how to build a Stratux.
  • A microSD card, 16 GB or larger, from a known brand. Use a new card so you can keep your current one as a backup.
  • A computer with a card reader (Windows, macOS or Linux).

Write the image to the microSD card

With Raspberry Pi Imager

  1. Install Raspberry Pi Imager and open it.
  2. Choose Device: pick your Raspberry Pi model.
  3. Choose OS: scroll to the bottom, pick Use Custom and select the .zip you downloaded. There's no need to unzip it.
  4. Choose Storage: pick your microSD card. Double-check it's the card and not another drive.
  5. Click Next. When asked about OS customisation, choose No. Then confirm to write.
Don't use OS customisation (Wi-Fi, username or hostname). Stratux NX sets up its own network and user. Custom settings can stop it from working.

With balenaEtcher

  1. Install balenaEtcher.
  2. Click Flash from file and select the .zip.
  3. Click Select target, pick the microSD card, then Flash!

First boot

Put the card in the Raspberry Pi, check that the radios and GPS are plugged in, and connect power. Use a supply that delivers at least 2.5 A (3 A for a Raspberry Pi 4). Weak supplies cause reboots that look like software problems.

The first boot takes a few minutes while the card is prepared. After that, the Stratux starts in under a minute.

Connect your tablet

  1. On your tablet or phone, join the Wi-Fi network called Stratux.
  2. Open http://192.168.10.1 in a browser. You'll see the Stratux NX status page with radios, GPS and traffic.
  3. Open your EFB app. Most apps find Stratux on their own. See setup for ForeFlight, Garmin Pilot, SkyDemon and others.

The GPS needs a view of the sky. The first fix can take several minutes, especially if the GPS is new or has been off for a long time.

Optional: Internet, data limits and cloud

Stratux NX works without Internet. If you have Starlink, a phone hotspot or a router in the aircraft, it can join that network and share it with your devices:

  1. Open Settings, set WiFi Mode to AP+Client and join your network. The client connection uses 2.4 GHz.
  2. Open Internet Data and set your warning, per-device and session limits. See the Starlink guide.
  3. To use the cloud, open Flight Log, note the link code and enter it at app.stratuxnx.com.

Updating Stratux NX

You only flash the card once. After that:

  • With Internet: open Settings → Software Update and install the latest version.
  • Without Internet: download the .deb update package from the release on another device, then upload it in Settings → Software Update.

Updates keep your settings and your flight log.

Switching from Stratux, and back

Stratux NX runs on the same hardware as Stratux, so switching is only a matter of cards. Write down any settings you changed in your current Stratux (for example your ownship ICAO code), keep that card as a backup and flash Stratux NX to a new card. To go back, put the old card back in or flash an upstream Stratux release.

Troubleshooting

The Stratux Wi-Fi network doesn't appear

Wait five minutes on the first boot. If it still doesn't appear, write the card again and check the power supply. A red power LED that flickers on the Raspberry Pi usually means low voltage.

192.168.10.1 doesn't open

Make sure the tablet is joined to the Stratux network. Some phones leave a network with no Internet; tell the phone to stay connected. Turning off mobile data while testing also helps.

My EFB app shows no traffic

Check the status page first: the radios should show messages. On the ground you may receive little or no ADS-B. Then follow the steps for your app in the EFB guide.

Still stuck? Open an issue on GitHub with what you see on the status page.
