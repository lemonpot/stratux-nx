Starlink Mini in the cockpit: make your data last

Starlink makes it possible to have Internet in a small airplane, but the aviation plans for the Mini include 50 GB a month. This guide covers which plan applies in flight, what uses up the data, and how to keep each device under control.

Plan details checked November 2026. Starlink changes plans often, so confirm on starlink.com before you fly.

Which Starlink plan works in flight

Starlink's Roam plans support in-motion use up to 100 mph (87 knots), which rules out flight in most aircraft. For flight, Starlink sells General Aviation plans for the Starlink Mini:

Source: Starlink Help Center, Introduction to Starlink Aviation. See also AOPA's coverage of the change.

Starlink requires the Mini to be used as a carry-on device inside the cabin, not mounted on the airframe. This use is not certified or approved by the FAA. In the US, the portable electronic device rule (14 CFR 91.21, explained in FAA Advisory Circular 91.21-1D) applies to IFR flights and to air carrier and commercial operations. The pilot in command decides whether the device interferes with the aircraft's systems. Check the rules that apply to your aircraft and country.

Where 50 GB goes

Most of the data isn't used by the EFB. Phones, tablets and laptops treat Wi-Fi as unlimited and start large background downloads as soon as they join one. Typical amounts:

WhatTypical data
Phone, tablet or laptop system updateSeveral GB each
Photo library or cloud backup catching upHundreds of MB to several GB
Video streamingAbout 0.7 GB per hour in SD, 3 GB per hour in HD
One speed testUp to about 1 GB
The Starlink router itselfAbout 1 to 5 GB a month
EFB weather updates, messages, emailUsually tens of MB per hour

Video, speed test and router figures from Starlink's data usage guidance.

A pilot reported on BeechTalk using about 2 GB in one hour with only an iPhone and an iPad running ForeFlight, a two-minute video call and a few emails. At that rate a 50 GB plan lasts about 25 flight hours. With a passenger or two, it can go much faster.

Free settings that help

Before anything else, mark the Starlink network as a limited connection on every device. This stops most background downloads.

  • iPhone and iPad: Settings → Wi-Fi → tap ⓘ next to the network → turn on Low Data Mode.
  • Mac: System Settings → Wi-Fi → Details next to the network → turn on Low Data Mode.
  • Android: Wi-Fi settings → the network → Metered (the name varies by phone).
  • Windows: Settings → Network → Wi-Fi → the network → Metered connection.

Also: set a strong password on the Starlink Wi-Fi, don't run speed tests in flight, and ask passengers to download videos before the flight.

These settings help, but they depend on each device and each person. They don't show you who used what, and they don't stop a device that ignores them.

How Stratux NX limits each device

With Stratux NX, the Stratux joins the Starlink Wi-Fi and your devices join the Stratux Wi-Fi, as they already do for ADS-B. All Internet traffic then goes through the Stratux, which can measure and limit it per device.

Starlink MiniWi-Fi, 2.4 GHz band
Stratux NXAP+Client mode: measures, warns and pauses
Pilot iPadNo limit
Passenger iPhonePaused at 500 MB
Laptop250 MB limit
A paused device loses Internet only. It stays on the Stratux Wi-Fi, so its EFB keeps receiving traffic and weather.

What you can set

  • A warning when a device reaches an amount you choose.
  • A pause when a device reaches its limit. You can set a default and a different limit per device.
  • A session limit for everyone together, so one flight can't use the whole month.
  • Exceptions for devices that should never be paused, like the pilot's iPad.

See where the data went

The Internet Data page ranks the apps and services that used the most data in the session, so you can see if it was a system update, a photo backup or a video.

Set it up

  1. Install Stratux NX on your Stratux.
  2. Make sure the Starlink Mini's 2.4 GHz Wi-Fi is on. Set a password on it.
  3. On the Stratux page, open Settings, set WiFi Mode to AP+Client and join the Starlink network.
  4. Open Internet Data and set the warning, pause and session limits. Mark the pilot's iPad as an exception if you want.
  5. Have everyone join the Stratux Wi-Fi, not the Starlink one.

Limitations

  • Stratux NX only sees devices connected to the Stratux. A device joined directly to the Starlink Wi-Fi isn't counted or limited.
  • The Starlink app remains the official count for your plan. Stratux NX shows what went through the Stratux.
  • The Raspberry Pi's Wi-Fi is slower than Starlink. It's fine for weather, messages and email for a few people, but not for several video streams.
  • It works the same way with a phone hotspot or a cellular router.
